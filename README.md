#  Retail Sales Analysis

##  Project Overview

This project analyzes retail sales data using Python to uncover sales trends, customer purchasing behaviour, and business insights. The analysis includes data cleaning, exploratory data analysis (EDA), and visualizations to support data-driven decision-making.

##  Objectives

- Clean and prepare retail sales data.
- Analyze sales performance.
- Identify high-performing product categories.
- Compare regional sales.
- Generate business insights using Python.


## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Microsoft Excel


## Dataset

The dataset contains retail sales transactions including information such as:

- Order Date
- Sales
- Profit
- Category
- Region
- Product
- Customer
- Quantity


## Analysis Performed

- Data Cleaning
- Missing Value Analysis
- Duplicate Checking
- Sales Trend Analysis
- Category-wise Sales Analysis
- Regional Sales Analysis
- Business Insight Generation


## Key Insights

- Identified top-performing product categories.
- Compared sales performance across different regions.
- Analyzed sales trends over time.
- Generated business insights to support decision-making.
